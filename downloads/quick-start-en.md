# Getting Started with Hatta

Version 2.2 · 30-10-2026

1. Identify the scope: full identity, fonts only or co-branding. A fonts-only request does not authorize changing colors or adding logos.
2. Read the [full reference](https://almohammdin.github.io/hatta-brand-guide/downloads/brand-guide-en.md). Use the standards and assets from the same release.
3. For websites, use the [design tokens](https://almohammdin.github.io/hatta-brand-guide/downloads/tokens.json) and [CSS](https://almohammdin.github.io/hatta-brand-guide/downloads/brand.css).
4. Apply the personality and voice to suit the audience and deliverable.
5. Use original assets. Check font loading; enable `salt` for Arabic subheadings and disable it for body text and buttons. Use El Messiri for English.
6. Check mobile, final dimensions, contrast, exports and links. Complete all placeholders with approved information.

## Scope

- Full identity: logo, colors, fonts, pattern and voice, with a footer suited to the parties' roles.
- Fonts only: font families, weights and alternate letterforms. Preserve all other branding and functionality.
- Co-branding: identify the lead organization and each participant's role before arranging logos.

## Working with AI

Read the [English implementation instructions](https://almohammdin.github.io/hatta-brand-guide/downloads/implementation-en.md). Downloading instructions does not install a skill automatically. Provide the reference and instructions with your task, or use your platform's supported skill mechanism with the [original skill package](https://github.com/almohammdin/hatta-brand-guide/tree/main/skills/apply-hatta-brand).

## Interface quality

Read the [digital experience standards](https://almohammdin.github.io/hatta-brand-guide/downloads/digital-quality-en.md): mobile, motion, realistic data, Arabic and supported languages, and delivery checks.
